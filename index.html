🚀 Deploy pa GitHub (më e lehtë!)

Nuk do GitHub as token? Shkarko këtë paketë të vogël — vetëm 2 skedarë i ngarkon në Hugging Face Spaces (falas, ashtu si Render) dhe boti punon 24/7 me link të përhershëm.

📦 Shkarko paketën e lehtë (DeployLehte.zip)

Brenda ZIP-it ke edhe udhëzuesin hap-pas-hapi (UDHEZUES-DEPLOY.md). Hapat kryesorë: huggingface.co → New Space → Docker → Files → Upload app.py + Dockerfile → prit 2–3 min → hap URL-në → Add to Home screen. ✅

☁️ Deploy 24/7 (Render)

Kjo faqe vjen nga një server që fiket herë pas here. Për ta pasur gjithmonë të ndezur, shkarko kodin, ngarkoje në GitHub (falas) dhe lidhe me Render — ke llogari tashmë! 🎉

📦 Shkarko kodin (WaynisAI-Kodi.zip)

1. Zhzippe ZIP-in → do të kesh 14 skedarë.
2. github.com (në Chrome, "Desktop site") → New repository → emër: waynis-ai → Public → Create.
3. uploading an existing file → zgjidh të gjithë skedarët → Commit.
4. render.com → New → Web Service → lidh GitHub → zgjidh repon → Deploy.
5. Pas ~3 min: https://waynis-ai.onrender.com → hap në telefon → ⋮ → Add to Home screen. ✅ Përgjithmonë!

📲 App Android

Shkarko WaynisAI.apk direkt në këtë telefon — ky shkarkim vjen drejtpërdrejt nga serveri (pa dëmtime), ndryshe nga shkarkimi nga viewer-i i skedarëve.

📲 Shkarko WaynisAI.apk 📦 Shkarko si ZIP (WaynisAI-Instalo.zip)

Nëse APK të jep "App not installed", shkarko ZIP → hape me menaxherin e skedarëve → zhzippe → instalo WaynisAI.apk nga brenda. Madhësia e APK-së: 37 834 bajt.
